# Open API Hub

A comprehensive directory of free, public APIs for developers, built with Next.js and Tailwind CSS.

🚀 **Live Demo:** [https://open-api-hub-gules.vercel.app/](https://open-api-hub-gules.vercel.app/)

## Features

- **Extensive Directory:** Browse over 200 free APIs categorized by topic (Animals, Anime, Crypto, etc.).
- **Search & Filter:** Find exactly what you need with fast, responsive search.
- **Detailed API Pages:** View comprehensive information about each API, including endpoints and documentation links.
- **Internal Testing Tool:** Test API endpoints directly from the interface using the built-in proxy to bypass CORS restrictions.
- **Modern UI:** Designed with a sleek "Electric Teal" and "Deep Pure Black" theme using Tailwind CSS v4.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.
